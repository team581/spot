This flake targets an Orin Nano on the **Seeed reComputer Robotics J401** carrier.
Never flash NVIDIA developer-kit firmware onto it. Firmware provisioning is
separate from NixOS deployment; the [board module](https://github.com/team581/spot-2026/blob/main/nix/hardware/j401/default.nix)
preserves the firmware-provided device tree and disables automatic firmware updates.

## Connect

For direct Ethernet, give the laptop `192.168.69.171/24`, then:

```sh
bash tools/jetson-ssh.sh
```

The helper uses the repository's shared maintenance key for `team581` with
passwordless sudo. Set `SPOT_HOST` to override `192.168.69.170`.
The [maintenance config](https://github.com/team581/spot-2026/blob/main/nix/hosts/spot/maintenance.nix) bridges both Ethernet ports;
they are on the same network.

## First installation

<LinkButton href="../../downloads/" icon="download">
	Download a Jetson image
</LinkButton>

Download the installer ISO and its checksum from the downloads page. Verify the
checksum before writing the ISO to a USB drive.

To build locally:

<Tabs>
  <TabItem label="Linux / Nix">

    On ARM Linux with Nix installed and a case-sensitive Nix store:

    ```sh
    nix build path:.#installer
    ```

    The ISO is in `result/iso/`.

  </TabItem>
  <TabItem label="macOS">

    On Apple Silicon, start a Docker-compatible Linux runtime with Buildx, then
    run from the repository root:

    ```sh
    mise run jetson:installer
    ```

    The task writes `dist/installer/spot-installer.iso`. Configure the ARM64 Linux
    builder with at least 8 CPUs and 16 GiB of RAM, and reserve at least 60 GiB of
    free **Mac disk space** for the first build. The Linux VM's reported free space
    does not reflect the Mac's remaining space.
    BuildKit caches the Nix store on its case-sensitive Linux filesystem between
    builds. Host Nix is not required.

  </TabItem>
</Tabs>

Before installing, back up existing storage and verify hardware operation and the
partition layout in [the host config](https://github.com/team581/spot-2026/blob/main/nix/hosts/spot/configuration.nix). Use spare
storage for trials. With the target root and EFI partitions mounted at `/mnt`
and `/mnt/boot`, run on the installer:

```sh
sudo spot-install --root /mnt
```

The ISO includes the prebuilt Spot system and all runtime dependencies. Installation
does not require internet access or a repository checkout on the Jetson.

## Deploy to an existing NixOS installation

Run from the development checkout. The Jetson builds the system and downloads
through the laptop over SSH, so it needs no Internet access. Commits that CI has
built download prebuilt from `https://cache.spot.frc581.com`; anything else builds
on the Jetson, and keeping the SSH connection open is required until it finishes:

```sh
mise run jetson:remote-deploy
bash tools/jetson-ssh.sh spot-vision check-health --robot
mise run jetson:remote-deploy switch
```

Set `SPOT_CONFIG=spot-test` for the test unit on newer firmware. To build on the
laptop instead, use `nix run .#deploy -- test` with an `aarch64-linux` builder. To
substitute from the cache there, add its `extra-substituters` and
`extra-trusted-public-keys` from `tools/jetson-remote-deploy.sh` to
`/etc/nix/nix.custom.conf` and restart the Nix daemon.

Add new files to Git before deploying and keep the checkout unchanged between
`test` and `switch`. The **Jetson offline installer** workflow pushes both
configurations to the `spot-nix-cache` R2 bucket, signed by the
`NIX_CACHE_SIGNING_KEY` secret; push and wait for it before deploying to skip
on-device builds. `test` changes the running system but leaves the boot default
unchanged. There is no automatic deployment rollback. `check-health --robot`
checks robot and camera readiness; it does not certify hardware accuracy.

If `switch` reports that no systemd-boot is installed (a unit not set up from the
installer), run the built generation once with
`sudo NIXOS_INSTALL_BOOTLOADER=1 /root/spot-next/bin/switch-to-configuration switch`.

## Recover

Restore the saved boot configuration after a failed test:

```sh
bash tools/jetson-ssh.sh sudo /nix/var/nix/profiles/system/bin/switch-to-configuration test
```

Undo a persisted switch:

```sh
bash tools/jetson-ssh.sh sudo nixos-rebuild switch --rollback
```

If SSH is unavailable, select an older retained generation in the boot menu.
Rollback does not restore firmware or application state in `/var/lib/spot-vision`;
back up that directory before state changes. Inspect service logs with
`bash tools/jetson-ssh.sh sudo journalctl -u spot-vision -b`.
